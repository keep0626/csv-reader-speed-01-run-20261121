A faster drop-in for make.fun's csv-reader 1.0.0: reads broken CSV files (BOM, CRLF, stray CRs, quoted fields with doubled quotes, quote junk, unterminated quotes, short/long rows) and returns exactly csv-reader's `{columns, rows, errors}` answer, using slice-based field extraction with native indexOf jumps instead of a character-at-a-time loop.

Run: `node main.ts` (Node 22). It reads `/input/cases.json` and writes `/output/answers.json`.
